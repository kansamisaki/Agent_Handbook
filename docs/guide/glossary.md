# 核心术语字典

术语用于辨别边界。遇到一个名字，先问它解决什么问题、由哪一层实现、如何验证。

## Agent

根据目标与观察决定下一步、调用工具并更新状态的系统。

## Harness

包围模型的运行支架：上下文、工具、状态、预算、权限和验证。

## Workflow

由预先定义的步骤和分支推进的流程，可包含模型调用。

## Token

模型处理的序列单位，不等于一个字或一个单词。

## Embedding

将输入映射为向量表示，用于相似性或后续模型计算。

## Transformer

以注意力等模块处理序列的神经网络架构家族。

## Attention

根据表示间关系聚合信息的机制。

## Temperature

调整采样分布的参数，不是事实可信度。

## Context window

一次推理可处理的上下文与生成预算限制，具体规则依接口而定。

## Context engineering

为每轮决策选择、组织和更新上下文的工程过程。

## Tool calling

模型发出结构化动作请求，应用执行并返回结果的交互。

## JSON Schema

描述 JSON 结构与字段约束的规范。

## ReAct

将决策与工具行动、环境观察交替组织的模式。

## Planning

将目标拆成可执行步骤，并依据新证据调整。

## Handoff

将任务或控制权转交给其他执行单元。

## Checkpoint

运行过程中持久保存的状态快照或进度。

## Idempotency

同一业务操作重复提交时不重复产生预期之外的副作用。

## Outbox

将业务状态和待发送事件在本地事务中一起记录的模式。

## Memory

保存并在后续任务中使用交互信息的机制。

## Semantic memory

事实和偏好类长期记忆。

## Episodic memory

过去事件、过程和结果类记忆。

## Procedural memory

流程、方法或行为规则类记忆。

## TTL

数据或缓存的有效时间。

## RAG

在生成前或过程中检索外部信息并提供给模型。

## Chunk

为存储或检索而划分的文档片段。

## BM25

基于词项匹配与统计权重的关键词排序方法。

## Hybrid search

组合关键词与语义等多种检索信号。

## RRF

用候选的排名而非不可比原始分数进行融合。

## Reranker

对已召回候选进行更精细相关性排序的模型或算法。

## HNSW

基于图的近似最近邻索引方法。

## Recall@k

前 k 个结果覆盖全部相关项的比例。

## Precision@k

前 k 个结果中相关项的比例。

## MRR

第一个相关结果排名倒数的平均值。

## nDCG

考虑相关性等级与位置折损的排序指标。

## MCP

连接 Agent 应用与工具、资源等能力的协议。

## A2A

Agent 间能力发现与任务交互的互操作协议。

## SSE

服务器通过 HTTP 向客户端持续推送事件的机制。

## Backpressure

当下游处理不足时限制上游输入，避免无界积压。

## Prefill

处理输入上下文并准备生成状态的阶段。

## Decode

逐步生成输出 token 的阶段。

## KV cache

缓存注意力键值表示以减少重复计算的机制。

## TTFT

从请求到第一个输出 token 的时间，测量边界需说明。

## TPOT

输出 token 之间平均耗时的一种测量方式。

## Continuous batching

动态合并进行中的推理请求以提升资源利用率。

## Quantization

用更低精度表示权重或中间数据的技术。

## SFT

使用示例输入输出进行监督微调。

## LoRA

通过低秩参数增量适配模型的方法。

## DPO

使用成对偏好优化模型相对选择的方法。

## RL

通过环境反馈和奖励学习策略的方法族。

## Eval

对任务表现进行可重复测量的过程。

## Grader

按照规则、模型或人工标准判定任务表现的评分器。

## Trace

一次执行跨步骤与服务的记录。

## SLO

面向服务表现的可测量目标。

## p95

95% 样本不超过该值的分位数。

## Prompt injection

通过不可信内容诱导系统偏离授权指令的攻击。

## RBAC / ABAC

基于角色 / 属性进行访问控制的方式。

## Sandbox

限制执行环境能访问的资源和能力的隔离机制。

## HITL

在流程中引入人的判断、确认或接管。

## Ablation

移除某组件进行对照，以判断其实际贡献。

## Data leakage

训练或调参中接触测试答案，导致评估偏乐观。
