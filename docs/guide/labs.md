## 使用方法

先阅读对应章节，写下你对结果的预测，再打开实验验证。若结果与你的预测不同，回到公式和系统边界分析原因，而不是记住滑块位置。

实验为了可解释性做了简化。例如检索使用人工设定的归一化分数；显存使用标准 KV 估算；成本假设各轮输入为平均值。它们不替代真实模型、真实硬件和真实任务集的测量。
